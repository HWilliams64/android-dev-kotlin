Fully Online Asynchronous Kotlin 15 Modules

About This Course

Turn your programming experience into Android apps. You will use Kotlin and Android Studio to design screens, respond to users, save information, and connect to web services. App mini-projects grow in complexity as you work toward a REST-connected Note-Taking App and a final app of your own design.

This fully online, asynchronous course is designed for students with programming experience. There are no scheduled class meetings. A user interface (UI) is the part of an app that people see and use. A back end is the service that supports the app behind the scenes. You will connect these parts while considering usability, authentication, and security.

Course Schedule

The course has 15 modules, with one module every week. Work steadily throughout the week and follow the due dates shown in Canvas.

  • Open Canvas Modules and complete the Learning Materials before the Deliverables. Review the slides, watch the videos, read the assigned resources, and practice. Then complete the graded discussion and any assignment or project work listed for that week.
  • Each module includes a graded discussion about how its concepts appear in real-world apps. The separate Question Board is encouraged and has no participation minimum.
  • Assignments are Android app mini-projects that increase in complexity. Follow Canvas for the assigned work; the course plan does not list a separate app assignment in every module.
  • Note-Taking App — Module 12: Connect your app to a REST API, a web service that lets the app read and send information. Final Project — Module 15: Create an application of your choice. Prepare your proposal and user interface prototype in Module 13.
  • Start early: Give yourself ample time to build, test, debug, and record your app. The projects take sustained work; do not wait until the submission deadline.

Development Environment

Install Android Studio on your computer. It is the main development environment for building and testing your Android apps.

  • Android Studio: Write app code in Kotlin, build screens, run your app, and investigate errors. Android Studio installation instructions.
  • Grader Than Workspace: Open this browser-based development environment through Canvas for demonstrations, basic Kotlin examples, and server components. It is not the general Android app development environment for this course.
  • Learning materials: Module 1 uses interactive Jupyter notebooks, which combine explanations and runnable code. Modules 2–15 provide video titles and assigned reading links on their Resources pages.
  • Canvas submissions: Upload a video of yourself using your app to the Canvas assignment. The Grader Than autograder is not used to submit or grade these app assignments.
  • Revisions: You may revise and resubmit assignments as many times as you like until the end of class. Read your feedback in Canvas and use it to improve your work.

Student Learning Outcomes

Upon completion of this course, you will be able to:

  • Use Kotlin flow control, branching, data structures, and object-oriented design.
  • Design and prototype user interfaces with the Android layout editor, XML resources, buttons, clickable images, menus, pickers, and RecyclerView.
  • Respond to keyboard and touch input.
  • Customize interfaces with drawables, styles, and themes.
  • Navigate between activities using intents.
  • Write and inspect Logcat messages to debug apps.
  • Explain the activity lifecycle and its callbacks.
  • Coordinate background work and interface updates using suitable Android services and scheduling tools, including broadcast receivers, AlarmManager, WorkManager, and JobScheduler.
  • Build internet-connected apps that manage network state and use HTTP GET and POST requests to display web API data.
  • Save and load device data.
  • Declare and request permissions for protected resources.
  • Create and manage notifications.
  • Plan efficient network transfers using connectivity, radio, and battery state, batching, prefetching, and scheduled work.
  • Capture photos with the device camera.
  • Compare Android community technologies, frameworks, languages, and backend services.
  • Explain user authentication, mobile security, publishing, and app monetization.

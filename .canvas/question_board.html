Ask Questions

Learning a new programming language and mobile platform brings new questions, even when you already have programming experience. Use this board to ask about Kotlin concepts, Android Studio, app behavior, course resources, or assignment instructions.

Questions are encouraged. There is no required participation minimum for this Question Board.

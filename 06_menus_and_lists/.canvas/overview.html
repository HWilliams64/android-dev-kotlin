Module 06 Overview: Menus and Lists

CSC-244 Android Development With Kotlin

Overview

In this module, we will discuss several UI features in-depth. We will explore how to create menus. We will learn about how to implement a list view. Work on Android apps in Android Studio installed on your computer. Grader Than Workspace supports demonstrations, basic Kotlin examples, and server components. Complete one module each week. Submit assigned app demonstration videos in Canvas; you may revise and resubmit until the end of class. Start early and leave time to test.

Key Concepts

  • Menu: a group of actions offered to the user
  • Menu item: an individual action a user can choose
  • List view: a screen element that displays a series of items
  • Item selection: a user choosing an entry from a menu or list

Outcomes

Upon completion of this module, students will be able to:

  • Create a menu of app actions.
  • Explain what a menu item lets the user do.
  • Display a list of related items.
  • Describe how a selected item relates to the intended user action.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • Which actions should be grouped into a menu?
  • How does a list help someone compare related items?
  • What should the app make clear after a user chooses an item?

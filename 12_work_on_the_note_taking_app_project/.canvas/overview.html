Module 12 Overview: Work on the Note-Taking App Project

CSC-244 Android Development With Kotlin

Overview

In this module, you will spend your time working on the Note-Taking App Project. Please use this time wisely, this project is time-consuming. Work on Android apps in Android Studio installed on your computer. Grader Than Workspace supports demonstrations, basic Kotlin examples, and server components. Complete one module each week. Submit assigned app demonstration videos in Canvas; you may revise and resubmit until the end of class. Start early and leave time to test.

Key Concepts

  • Note workflow: the steps a user follows to manage a note
  • REST API connection: exchanging note information with a web service
  • App and service data: information moving between the screen and the server
  • Project planning: dividing a larger app into manageable work

Outcomes

Upon completion of this module, students will be able to:

  • Describe the user task your Note-Taking App supports.
  • Connect the app to the project’s REST API.
  • Demonstrate how note information moves between the app and service.
  • Plan and check the work needed to complete the project.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • What does a user need to do with a note?
  • How will you tell whether the app and service exchanged the intended data?
  • Which parts of the project need the earliest attention?

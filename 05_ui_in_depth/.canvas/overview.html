Module 05 Overview: UI in Depth

CSC-244 Android Development With Kotlin

Overview

In this module, we will discuss several UI features in-depth. We will talk about how to create and apply styles and themes, adding drawables to your app, and working with animation. Work on Android apps in Android Studio installed on your computer. Grader Than Workspace supports demonstrations, basic Kotlin examples, and server components. Complete one module each week. Submit assigned app demonstration videos in Canvas; you may revise and resubmit until the end of class. Start early and leave time to test.

Key Concepts

  • Style: shared appearance settings for interface elements
  • Theme: appearance settings applied across an app or activity
  • Drawable: a graphic resource an app can display
  • View animation: a visible change in a screen element over time

Outcomes

Upon completion of this module, students will be able to:

  • Create and apply a style.
  • Apply a theme to coordinate an interface.
  • Add drawable resources to an app.
  • Animate a view changing position or visibility.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • How does a consistent visual style help users recognize actions?
  • What information can a drawable communicate?
  • When does animation clarify an action, and when can it distract?

Module 02 Overview: Creating Your First App

CSC-244 Android Development With Kotlin

Overview

In this module, we will explore the very basics of Android Studio, by setting up your development environment. We will create a simple app that will display text on the screen. Work on Android apps in Android Studio installed on your computer. Grader Than Workspace supports demonstrations, basic Kotlin examples, and server components. Complete one module each week. Submit assigned app demonstration videos in Canvas; you may revise and resubmit until the end of class. Start early and leave time to test.

Key Concepts

  • Android Studio: the local tool used to build Android apps
  • Android project: the files and settings that make up an app
  • Text display: a small first step toward a useful screen
  • Emulator: a virtual Android device used to run an app

Outcomes

Upon completion of this module, students will be able to:

  • Install Android Studio on your computer.
  • Create an Android project.
  • Build a simple app that displays text.
  • Run the app on an Android emulator.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • What does a useful first screen tell a user?
  • How does running an app help you check what you built?
  • What can a virtual device help you observe before testing on a phone?

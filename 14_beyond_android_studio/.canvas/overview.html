Module 14 Overview: Beyond Android Studio

CSC-244 Android Development With Kotlin

Overview

In this module, you will explore tools that extend mobile app development. Backend services support an app behind the scenes. Cross-platform frameworks help developers build for more than one operating system. Game engines provide tools for building interactive games. Work on Android apps in Android Studio installed on your computer. Grader Than Workspace supports demonstrations, basic Kotlin examples, and server components. Complete one module each week. Submit assigned app demonstration videos in Canvas; you may revise and resubmit until the end of class. Start early and leave time to test.

Key Concepts

  • Backend service: remote support for app data or operations
  • Cross-platform framework: tools for building for more than one platform
  • Game engine: tools for building interactive game experiences
  • Technology fit: choosing tools to match an app’s needs

Outcomes

Upon completion of this module, students will be able to:

  • Describe a role a backend service can play in a mobile app.
  • Explain the purpose of a cross-platform development framework.
  • Identify how a game engine supports game development.
  • Compare technology options against a concrete app idea.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • When does an app need help from a backend service?
  • What tradeoffs arise when one project targets multiple platforms?
  • When might a game engine fit better than ordinary app interface tools?

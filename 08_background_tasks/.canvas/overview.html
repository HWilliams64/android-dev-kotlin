Module 08 Overview: Background Tasks

CSC-244 Android Development With Kotlin

Overview

In this module, we will discuss how to run background tasks using threads and Android work managers. Work on Android apps in Android Studio installed on your computer. Grader Than Workspace supports demonstrations, basic Kotlin examples, and server components. Complete one module each week. Submit assigned app demonstration videos in Canvas; you may revise and resubmit until the end of class. Start early and leave time to test.

Key Concepts

  • Thread: a path along which program instructions run
  • Background task: work that happens outside the immediate screen interaction
  • Service: an Android component for work without its own user interface
  • Work scheduling: arranging when background work should run

Outcomes

Upon completion of this module, students will be able to:

  • Explain why lengthy work can interfere with screen interaction.
  • Run a task on a background thread.
  • Describe the purpose of an Android service.
  • Identify work that should be scheduled instead of started immediately.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • What work should continue while a user interacts with an app?
  • How could slow work change the experience of tapping a button?
  • When is it reasonable for an app to wait before doing a task?

Module 03 Overview: Working With the UI Editor

CSC-244 Android Development With Kotlin

Overview

In this module, we will walk through the basics of how to design a simple user interface. We will discuss how to edit assets with the editor and with XML. Finally, we will programmatically connect the UI elements with the code as we discuss views. Work on Android apps in Android Studio installed on your computer. Grader Than Workspace supports demonstrations, basic Kotlin examples, and server components. Complete one module each week. Submit assigned app demonstration videos in Canvas; you may revise and resubmit until the end of class. Start early and leave time to test.

Key Concepts

  • User interface (UI): the screen elements a person sees and uses
  • Layout editor: the visual tool for arranging a screen
  • XML layout: a text description of screen structure
  • Views: interface elements that code can work with

Outcomes

Upon completion of this module, students will be able to:

  • Arrange elements in the Android layout editor.
  • Identify the XML that describes a layout.
  • Explain how resource files support a screen.
  • Connect a screen element to Kotlin code.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • How does a screen layout help someone find the next action?
  • What can you change visually or through layout XML?
  • How does connecting a view to code turn a picture into an interactive app?

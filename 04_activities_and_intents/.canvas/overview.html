Module 04 Overview: Activities and Intents

CSC-244 Android Development With Kotlin

Overview

In this module, we will learn about Activities and their life cycles. We learn how to move from one activity to the next. We will learn how to write to the log as well as read from the log. Work on Android apps in Android Studio installed on your computer. Grader Than Workspace supports demonstrations, basic Kotlin examples, and server components. Complete one module each week. Submit assigned app demonstration videos in Canvas; you may revise and resubmit until the end of class. Start early and leave time to test.

Key Concepts

  • Activity: an Android component that supports a user-facing task
  • Intent: a message that requests an action from an Android component
  • Activity lifecycle: the states an activity moves through
  • Logcat: a tool for reading messages that help explain app behavior

Outcomes

Upon completion of this module, students will be able to:

  • Move from one activity to another using an intent.
  • Describe activity lifecycle changes when a user leaves and returns.
  • Write useful log messages.
  • Read Logcat to investigate the order of app events.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • What should happen when a user moves between app screens?
  • What might change when an activity leaves the foreground?
  • How can a record of events help explain an unexpected result?

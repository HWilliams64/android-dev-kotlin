Kotlin Basics connects your Java and C++ experience to the language used throughout this Android course. You will practice Kotlin syntax, safe handling of missing data, classes, collections, and common function patterns. The lessons build toward a small notes model that adds, changes, finds, and removes data. A notes app uses these same language decisions beneath its screens, even though this module tests them with text output.

1. [Kotlin Syntax and Flow Control](01_kotlin_syntax_and_flow_control.ipynb) — use bindings, templates, conditional expressions, and loops. [Watch video (6:23)](media/01_kotlin_syntax_and_flow_control/lesson.mp4).
2. [Functions and Null Safety](02_functions_and_null_safety.ipynb) — reuse behavior and distinguish missing text from empty text. [Watch video (6:26)](media/02_functions_and_null_safety/lesson.mp4).
3. [Classes, Properties, and App Data](03_classes_properties_and_app_data.ipynb) — model related values, copy data objects, and implement interfaces. [Watch video (7:16)](media/03_classes_properties_and_app_data/lesson.mp4).
4. [Collections and Lambdas](04_collections_and_lambdas.ipynb) — select, transform, search, and visit groups of app data. [Watch video (8:00)](media/04_collections_and_lambdas/lesson.mp4).
5. [Kotlin Patterns for Android](05_kotlin_patterns_for_android.ipynb) — recognize callbacks, extensions, scope functions, and initialization patterns. [Watch video (6:05)](media/05_kotlin_patterns_for_android/lesson.mp4).
6. [Build a Notes App Model](06_build_a_notes_app_model.ipynb) — combine the earlier lessons in a tested in-memory model. [Watch video (6:37)](media/06_build_a_notes_app_model/lesson.mp4).

Work through the notebooks in order during this module's week. Plan roughly 35–50 minutes per notebook including practice; your time may vary. Begin early and leave time to test and revise. The notebook exercises are practice; consult the Canvas assignment for the graded Kotlin Overview requirements.

Use the course's Java Workspace with the [Kotlin dependency](../dependencies/install-kotlin-kernel.sh) installed. Select **Kotlin** for notebook code cells. Begin each notebook with a fresh kernel session; restart it when you want to test the whole notebook from the beginning. Run programming cells individually in order; the separate text-response cells are places to write, not code to execute. Avoid **Run All**, which can attempt to execute those written responses in this Workspace client.

The videos use saved `demo.kts` files and the editor's **Run Code** button. That button uses the installed Kotlin compiler and displays results in the Output panel. Save a script before running it. Notebook cells keep earlier definitions in their kernel session, while each script run starts a new program, so include every needed declaration in a standalone script.

Each notebook includes a captioned video, a transcript, guided practice, hidden explained answers, and official reading links. Try a task before opening its answer. The animated diagrams have hide/show controls and still alternatives. Use the [module glossary](terms.md) when you need a reminder of a term.

Android Studio is required on your own computer for Android app development in the following modules. Workspace supports basic Kotlin demonstrations and later server examples; assignments are submitted in Canvas, not Workspace. Follow each Canvas assignment's video-upload instructions. You may resubmit through the end of class.

The separately provided `00_hello_world.ipynb` is an optional workspace orientation. It teaches selecting the Kotlin kernel and running a first cell before these six language lessons.

Module 01: Wrapping-up and Looking Ahead

CSC-244 Android Development With Kotlin

Wrapping Up

  • Use Kotlin bindings, expressions, functions, and null handling to make app rules explicit.
  • Model related data with classes, then use collections and lambdas to process it.
  • Combine these skills in a notes model and test both successful operations and missing-note cases.

Looking Ahead

  • Next, Module 02 uses Android Studio to create and run your first app.
  • Connect the Kotlin rules you practiced here to a simple screen and test the app in its Android environment.

Module 01 Overview: Kotlin Basics

CSC-244 Android Development With Kotlin

Overview

In this module, we learn about the basics of the Kotlin programming language. We will learn programmatic flow control, branching, data structures, and how to make basic classes. Use the Jupyter notebooks in Grader Than Workspace for this Kotlin foundation. Install Android Studio on your computer for the app development that follows. Complete one module each week. Submit assigned app demonstration videos in Canvas; you may revise and resubmit until the end of class. Start early and leave time to test.

Key Concepts

  • Branching: choosing a path when a condition is met
  • Loops: repeating an action for several items or steps
  • Collections: organizing related values in lists, sets, and maps
  • Classes and objects: modeling information and behavior together

Outcomes

Upon completion of this module, students will be able to:

  • Use Kotlin conditions to choose which action runs.
  • Use loops to process a sequence of values.
  • Choose a list, set, or map for a small data problem.
  • Create a basic class and use objects made from it.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • How could an app decide which message to show a user?
  • When does app information need a list, a set, or a map?
  • How could a class represent something a user manages?

Module 01 Overview: Kotlin Basics

CSC-244 Android Development With Kotlin

Overview

Kotlin Basics connects your Java and C++ experience to Android development. Work through six sequenced notebooks on syntax, functions, missing data, classes, collections, and common Kotlin patterns. Finish by testing a small notes model before adding a screen. Complete this module during its scheduled week, start early, and allow time to revise. Use Workspace for these Kotlin foundations and install Android Studio on your computer for the app development that follows. Follow Canvas for graded work and video submission requirements; resubmissions remain open until the end of class.

Key Concepts

  • Bindings and flow control: store values, choose a result, and repeat work
  • Functions and null safety: reuse rules and handle missing values
  • Classes and interfaces: organize app data and behavior
  • Collections and lambdas: select, transform, and search groups of values
  • Kotlin app patterns: configure objects and pass callback behavior
  • Model testing: check complete operations and missing-data cases

Outcomes

Upon completion of this module, students will be able to:

  • Use Kotlin bindings, templates, conditions, and loops to implement a small rule.
  • Write reusable functions that distinguish present, missing, and empty text.
  • Create data classes and interface implementations with clear properties.
  • Filter, transform, search, and visit app data with collection functions.
  • Explain callbacks, extension functions, and scope functions in small Kotlin examples.
  • Build and test an in-memory model that adds, updates, finds, and removes notes.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • How should an app behave when information is missing or empty?
  • How can classes, collections, and functions divide the work behind a screen?
  • What tests would reveal a broken data rule before a user interacts with the app?

Module 09 Overview: Volley

CSC-244 Android Development With Kotlin

Overview

In this module, we will learn about how to make HTTP requests to web APIs using the Volley library. Work on Android apps in Android Studio installed on your computer. Grader Than Workspace supports demonstrations, basic Kotlin examples, and server components. Complete one module each week. Submit assigned app demonstration videos in Canvas; you may revise and resubmit until the end of class. Start early and leave time to test.

Key Concepts

  • HTTP request: a message asking a web service to do something
  • Web API: an interface apps use to exchange information with a service
  • Volley: an Android library for sending network requests
  • Request queue: a structure that manages requests waiting to be handled

Outcomes

Upon completion of this module, students will be able to:

  • Explain how an app uses an HTTP request to reach a web API.
  • Set up a Volley request queue.
  • Send a simple request using Volley.
  • Describe how returned information supports an app screen.

Guiding Questions

Consider the following questions as you review the learning resources this week:

  • What information does an app need from a remote service?
  • What should the user see while information is being requested?
  • How could a failed request affect the task a user is trying to finish?
